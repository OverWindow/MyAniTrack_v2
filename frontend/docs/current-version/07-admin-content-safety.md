# 관리자와 콘텐츠 안전

## 접근 제어

`/admin`은 인증 사용자 중 관리자 역할만 접근한다. 비로그인 사용자는 로그인 링크를, 권한 없는 사용자는 중립적인 접근 불가 상태를 본다. 권한 오류 원문은 toast로 전달된다. 백엔드 관리자 API도 토큰과 역할을 다시 검증하므로 프론트 조건만으로 권한을 신뢰하지 않는다.

## 운영 기능

관리 화면은 플랫폼 통계, 사용자 조회·상세, 애니 페이지/시즌/전체 동기화, 한국어 제목 번역, 연관 작품·캐릭터·성우·스튜디오 동기화, 시리즈 재계산을 제공한다. 장시간 작업은 실행 중 버튼을 잠그고 서버의 작업 응답과 상태를 카드에 남긴다.

사용자 관리자는 검색·역할·페이지 조건으로 사용자 목록을 조회하고 세부 계정 정보를 확인한다. 목록과 상세 요청은 독립 상태를 사용해 한쪽 실패가 다른 영역을 덮지 않는다.

## 콘텐츠 노출과 신고

작품 노출 재정의는 작품 ID, 노출 여부, 운영 사유를 저장한다. 이 값은 외부 동기화가 다시 실행되어도 운영자 판단을 보존한다. 프로필 신고 대기열은 사유, 신고자, 대상 사용자, 누적 횟수와 이미지를 보여주고 기각·이미지 제거·사용자 정지를 실행한다.

사용자에게 제공되는 애니 서비스는 `is_adult = FALSE`와 `app_visible = TRUE` 조건을 적용한다. 공개 사용자 API는 계정 moderation 상태와 차단 관계까지 확인한다. 관리자 작업 실패는 인라인 빨간 카드 대신 error toast를 사용하며 성공 응답은 기존 결과 카드에 유지한다.

## 시리즈 운영

시리즈 재계산은 관리자 데이터 동기화와 별개 작업이며 이미 실행 중인 경우 충돌 응답을 표시한다. 시리즈 서비스는 대표 작품, 사용자 진행, 필수 완주 구성과 제외 사유를 결합해 탐색·내 컬렉션·공개 컬렉션이 공유하는 응답 형태를 만든다.
