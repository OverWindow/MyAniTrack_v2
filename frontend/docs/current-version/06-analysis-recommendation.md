# 분석과 추천

## 분석 개요

`/analysis`는 로그인 사용자의 기록을 집계하고 비로그인 사용자는 샘플 분석을 보여준다. 요약에는 선호 장르, 총 작품 수, 완주·시청 중 수, 평균 점수, 감상 시간, 평균 방영 연도와 시리즈 통계가 포함된다. 새로고침은 관련 분석 캐시를 지우고 30초 cooldown 안에서 재계산 폭주를 막는다.

## 차트와 데이터

- 포맷 분포: TV·영화·OVA 등 작품 형식 비중
- 장르 분포·시청 시간·평균 점수: 작품 수와 실제 감상량을 분리
- 방영 연도: 연대 진행과 연도별 감상량
- 평점 분포와 연도별 점수: 점수대 및 시간 변화
- 장르 버블: 작품 수, 감상 시간, 평균 점수를 함께 표현
- 감상 DNA: 다양성·집중도·완주 성향·시리즈 완주 등 축을 정규화

차트는 lazy import와 Suspense를 사용해 초기 번들을 나눈다. 선택 가능한 장르·연도·점수 막대는 해당 작품 목록 toast 패널을 열어 상세 작품으로 이동할 수 있다.

## 스튜디오와 성우

스튜디오 랭킹은 작품 수·평균 점수·감상 시간 정렬을 제공하고 선택한 스튜디오의 작품을 표시한다. 성우 랭킹은 많이 본 성우와 평가 작품이 충분한 고평점 성우를 나누며, 선택한 성우의 캐릭터·작품 목록을 modal에서 탐색한다.

분석 응답은 사용자와 정렬별 키로 메모리/localStorage 캐시에 저장된다. 공개 사용자 분석은 별도의 user ID 키를 사용한다. 세부 섹션 오류는 전체 분석을 숨기지 않고 toast와 중립적인 섹션 상태로 처리한다.

## 추천과 해석 규칙

감상 시간은 작품 형식·에피소드·진행 화수 자료를 기반으로 계산된다. 데이터가 부족하면 0 또는 null로 정규화하고 차트는 빈 상태를 표시한다. 시리즈 완주 통계는 mainline 필수 작품 기준이며 제외 사유가 있는 구성 작품은 완주 분모에 포함하지 않는다.
