# 인증과 계정

## 로그인과 가입

이메일 로그인은 기기 이름과 안전하게 정규화한 복귀 경로를 인증 API에 전달한다. 이메일 확인이 필요한 계정은 인증 대기 화면으로 이동한다. Google 로그인은 Supabase OAuth를 시작하기 전에 복귀 경로와 가입/로그인 의도를 저장하고, `/auth/callback`에서 세션 교환과 약관 상태 확인을 마친다.

가입은 이메일·비밀번호·닉네임, 약관 동의, 닉네임 중복 확인을 조합한다. 닉네임 검증 결과는 입력 필드 가까이에 유지한다. 제출이나 OAuth 연결 실패처럼 화면 전체 작업의 오류는 toast로 표시하며 입력값은 보존한다.

## 이메일 인증과 비밀번호 재설정

- 인증 대기 화면은 이메일을 수정해 인증 메일을 재발송할 수 있다.
- 인증 확인 화면은 URL token을 검증해 완료 상태 또는 복구 이동을 제공한다.
- 비밀번호 재설정 요청은 계정 이메일로 링크를 전송한다.
- 확인 화면은 token, 최소 길이, 확인 비밀번호 일치를 검사한 뒤 새 비밀번호를 저장한다.

필드 자체의 즉시 검증 힌트는 인라인으로 남고, 네트워크·서버·토큰 처리 실패는 toast로 알린다.

## 프로필과 설정

프로필 화면은 사용자 정보와 배지를 보여주고 편집 화면으로 연결한다. 편집 화면은 닉네임 중복 확인, 소개 수정, 프로필 이미지 자르기와 업로드를 제공한다. 이미지 cropper는 PNG/JPEG 파일을 읽어 확대·회전·위치 조정 후 적용하며 파일 처리 실패도 toast로 전달한다.

설정은 프로필·보안·약관·화면 관련 섹션을 나눈다. 현재 약관 동의 상태를 API에서 읽고 비밀번호 재설정 메일을 요청할 수 있다. 외형·배치·언어 선택 중 로컬 설정은 브라우저 저장소에 유지한다.

## 계정 삭제와 정책

계정 삭제는 확인 문구를 정확히 입력한 뒤 인증된 삭제 API를 호출한다. 성공하면 로컬 인증 정보를 정리하고 완료 상태로 이동한다. 401 등 상태별 복구 동작은 유지하되 서버 오류 원문은 toast로 표시한다. 개인정보 처리방침과 연락처는 별도 정책 화면에서 제공한다.
