# 탐색과 작품 상세

## 작품 탐색

탐색 화면은 `anime`와 `series` 보기 방식을 갖는다. 작품 모드는 제목, 장르, 정렬, 한글/영문 표시 언어를 요청 키로 묶는다. 검색어는 550ms debounce되며 로그인 사용자는 내 컬렉션 상태가 포함된 검색 API를 사용한다. 비로그인 사용자는 검색어 유무에 따라 일반 검색 또는 목록 API를 사용한다.

첫 페이지 이후에는 IntersectionObserver가 sentinel을 감지해 커서 페이지를 불러온다. 이미 소비한 커서와 작품 ID를 추적해 반복 응답과 중복 카드를 막는다. 요청 키가 바뀐 이전 응답은 새 목록에 합치지 않는다.

작품 카드에서는 평균 점수, 컬렉션 추가 버튼, 로그인 사용자의 빠른 별점을 제공한다. 별점 작업은 컬렉션 추가 또는 수정 API를 호출하고 로컬 카드 상태와 컬렉션 캐시를 맞춘다.

## 시리즈 탐색

시리즈 모드는 `mainline`과 `franchise` 범위, 장르·정렬·검색·표시 언어를 지원한다. 카드에는 대표작, 평균 점수, 구성 작품 수와 포스터 스트립을 표시한다. 커서는 `seriesId`로 중복을 제거하며 별도의 sentinel과 로딩 상태를 사용한다. 작품/시리즈 전환 아이콘은 각각 Lucide `Film`, `Layers3`이다.

## 작품 상세

상세 화면은 작품 메타데이터, 포스터·배너, 장르, 방영 정보, 외부 링크, 컬렉션 편집기를 조립한다. 샘플 모드는 실제 기록 편집 대신 가입·로그인 안내를 보여준다. 관리자는 한국어 대표 제목과 부제목을 수정하고 잠글 수 있다.

연관 작품과 주요 캐릭터·성우는 상세 본문과 독립적으로 비동기 로드된다. 한 섹션의 실패가 나머지 상세 정보를 가리지 않으며 오류는 toast로 알린다. 치명적인 작품 조회 실패만 공통 재시도 상태로 전환한다.

## 성우 상세

성우 페이지는 기본 정보와 출연 캐릭터를 페이지 단위로 불러온다. 로그인 사용자는 전체 출연작과 내가 완주한 작품을 전환할 수 있다. 추가 로딩 실패는 기존 목록을 유지한 채 toast만 표시하고 다시 더 보기를 시도할 수 있다.
